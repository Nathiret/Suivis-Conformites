T.I.S – Suivi Conformités

Pour connecter cette application à ton Google Sheets, tu dois d'abord déployer un petit script sur ton compte Google (Apps Script). C'est gratuit, rapide, et ne se fait qu'une fois.

Configuration initiale (5 min)

1
Ouvre ton Google Sheets → Extensions → Apps Script
2
Efface le contenu par défaut, colle le contenu du fichier Code.gs (fourni avec cette app), puis Enregistrer
3
Clique Déployer → Nouveau déploiement → Type : Application Web → Accès : Tout le monde → Déployer
4
Autorise les permissions demandées, puis copie l'URL de déploiement ci-dessous

L'URL est sauvegardée dans ton navigateur (localStorage). Elle ne quitte jamais ce site.
